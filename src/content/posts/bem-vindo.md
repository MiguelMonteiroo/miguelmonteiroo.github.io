Este é o primeiro post. Aqui vou compartilhar meus estudos e projetos.

## Como funcionam os posts

Os posts são arquivos Markdown no diretório `src/content/posts/`. Basta criar um novo arquivo `.md` com o frontmatter contendo `title` e opcionalmente `tags`.

A data de publicação é extraída automaticamente do histórico do git — especificamente, do timestamp do primeiro commit que adicionou o arquivo.

## Markdown suportado

- **Negrito** e *itálico*
- Listas ordenadas e não ordenadas
- `Código inline` e blocos de código
- Imagens
- Citações
- Links
