# Astro + GitHub Pages para site pessoal estático

O site é Markdown puro no repositório, sem backend. Escolhemos Astro por ser um framework SSG moderno com suporte nativo a Markdown, zero JavaScript por padrão, e deploy trivial em GitHub Pages gratuitamente. Astro substitui alternativas como Next.js (mais complexo, JS pesado) e Hugo/11ty (menos integração com o ecossistema JS moderno). GitHub Pages é grátis e dispensa configurar servidor ou CDN.
